# Halo Software Homebrew Tap

Official Homebrew tap for Halo Software applications.

## Installation

To install **Notes by Halo** (macOS Apple Silicon arm64):

```bash
brew tap halo-software/tap
brew install --cask notes-by-halo
```

## Security Notice
Notes by Halo is distributed unsigned without Apple Developer notarization. If macOS blocks opening the app on first launch, allow it via:
**System Settings** -> **Privacy & Security** -> **Open Anyway**
(システム設定 -> プライバシーとセキュリティ -> 「このまま開く」).
